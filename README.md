# 豬病圖譜搜尋與症狀鑑別系統 V16.1 FIX

## V16 新增：首頁風險雷達＋每日優先工作清單

V16 將先前建立的疾病事件、病例追蹤、送檢、治療方案、歷史成效與 AMR 監測整合回首頁。

### 今日風險雷達
首頁以六個維度顯示相對風險：
- 病例惡化
- 今日死亡
- 待送檢／待結果
- 治療無反應
- AMR／R 警示
- 跨棟共同訊號

系統顯示低／中／高／極高風險與相對分數。

這些分數只用於牧場內的工作排序，不是疾病發生機率、死亡預測或官方風險分級。

### 今日優先工作清單
系統依既有資料自動產生今天要處理的工作，例如：
- 惡化病例
- 待送／待檢
- 檢驗中的結果追蹤
- 治療惡化
- 治療無明顯反應
- 進行中方案需要補成效紀錄
- R 集中訊號
- 跨棟共同症候群

優先級分為：
- 立即
- 高
- 一般

### 直接跳轉
每一件工作都有「開啟」按鈕，可直接進入：
- 病例追蹤
- 採樣檢驗
- 治療成效
- 抗菌藥監測
- 疾病事件中心

### 今日勾選狀態
完成工作後可直接勾選。
勾選只保存當天，並依日期區分；可按「重設今日勾選」。

### 重要限制
- 風險雷達是管理優先順序工具，不是臨床診斷或疾病發生概率。
- AMR 警示只使用系統中已輸入的 S/I/R 紀錄。
- 跨棟訊號代表多棟出現相似疾病／症候群，不等於已證實跨棟傳播。
- 今日工作清單不能取代場內巡欄、獸醫師判斷或法定疫病通報。
